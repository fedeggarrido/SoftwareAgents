# Code of Conduct

SoftwareAgents is a personal project maintained by Fede García. Contributions, issues and
discussion are welcome as long as they stay respectful:

- Be kind and assume good faith. Critique code and ideas, not people.
- No harassment, discrimination, personal attacks or sharing other people's private information.
- Keep discussions on topic and constructive.

The maintainer may edit, hide or remove comments, issues or pull requests that break these
rules, and block repeat offenders. To report a problem privately, contact the maintainer through
their [GitHub profile](https://github.com/fedeggarrido).

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
